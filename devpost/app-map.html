Interactive Code Tour, Architectural Stops, and Practices to Reuse

⚡ What ErrorSpeak Does

ErrorSpeak is a CPU-native, sub-100ms terminal triage console. It ingests cryptic stack traces (Python, Node.js, Git, Docker, Web), runs local pattern decomposition, and outputs a plain-English explanation alongside a 1-click verified terminal remediation command.

🔄 Data & Execution Flow

📍 3-Stop Code Tour

Stop 1 • Entry Point
Terminal Editor & Preset Trigger
src/components/TerminalInput.jsx & src/components/PresetRibbon.jsx

Captures developer keystrokes or one-click preset selection. Triggers automatic runtime environment detection.

Stop 2 • The Triage Kernel
Deterministic Parser & Heuristic Matcher
src/engine/parser.js & src/engine/presets.js

Decomposes stack traces into structured JSON: isolates offending file, line number, plain English translation, and verified shell commands.

Stop 3 • Remediation Card
Interactive HUD & 1-Click Clipboard Action
src/components/TriageCard.jsx

Renders severity meters, fault highlights, plain English vs TL;DR toggles, and handles copy-to-clipboard with confetti feedback.

🛠️ To Change This, Start Here

  • To add a new preset error: Add a new entry to ERROR_PRESETS in src/engine/presets.js.
  • To customize triage heuristics: Edit parseError() in src/engine/parser.js.
  • To adjust HUD colors or fonts: Update classes in src/components/TriageCard.jsx and src/index.css.

💡 A Practice to Reuse

The "Deterministic Dual-Engine" Pattern: For AI-powered developer tools and hackathon demos, never rely solely on cloud APIs that can suffer from latency, rate limits, or connectivity issues. Building a smart client-side heuristic engine with instant offline presets ensures your app is 100% reliable during high-stakes pitches and live video recordings.
