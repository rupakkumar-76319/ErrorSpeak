🚀 The Core User Journey

Step 1
Arrival & Preset
Opens HUD; selects 1-of-5 presets or pastes stack trace.
Step 2
Local Triage
Auto-detects runtime (Python, Node, Docker) & fault line in <100ms.
Step 3
Inspection
Reads plain-English translation + pinpoint fault line.
Step 4
Remediation
Clicks "Copy Fix Command" to execute verified solution.

🖥️ Visual Surfaces & Workspace Layout

A unified developer HUD engineered for maximum demo impact and speed:

SURFACE 1

Terminal Ingestion Console

Monospace editor with sample preset ribbon, live character count, and run action button.

✓ Instantly triggers on preset click without full page refresh.
SURFACE 2

Triage & Remediation Card

Severity gauge, fault line highlight, plain-English summary, and 1-click copyable shell command.

✓ Copy button triggers visual feedback and clipboard write.

🛡️ States & Boundaries

  • Empty State: Monospace blinking terminal cursor with contextual guide chips.
  • Analyzing State: Smooth scanning animation (<200ms) with runtime detection badge.
  • Success State: Populated 3-layer diagnostic card with copyable terminal fix.
  • Offline Resilient: Works completely offline with zero API calls required for presets.
